# Music Bridge

Transfer music playlists seamlessly across different streaming platforms.

## Problem Statement
Music playlists are locked within individual platforms, making it difficult for users to switch services without losing their curated collections.

## Solution
Music Bridge allows users to extract playlist data from one platform and recreate it on another, eliminating the need to manually rebuild playlists.
